# SkillForge Quick Start

Two commands to get set up:

```
/plugin marketplace add panviva/upland-marketplace
/plugin install skillforge --scope user
```

Then type `/skillforge-onboarding` in Claude Code and it will walk you through the rest (Okta access, API key, project init).

> **Need access?** Ask your admin to add you to the `skillforge-panviva` Okta group before you start.
